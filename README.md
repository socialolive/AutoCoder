# AutoCoder
AutoCoder is a Hyperskill project part of "DevOps Engineer with AI" course.

AutoCoder is an automated code generation tool that leverages AI to streamline your development
process by generating boilerplate code, templates and other repetitive structures based on issues
and predefined patterns.

## Features
- **Code Templates:** Jumpstart your projects with a variety of language-specific templates;
- **Customizable Generation:** Tailor the generated code to your specific needs by specifying your prompt as a GitHub issue; 
- **Integration Support:** Works as part of your CI/CD pipeline using workflows with GitHub Actions;
